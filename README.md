This repository contains a demo for a statistical LSTM-based model.
It was made just as a demo for a Hackathon in order to support my group's project.
Any suggestion or change you want to do is fine.

The progeram is able to give a solution based on which bus line is more saturated and save that solution.
It uses Streamlit so if you want to run it you would have to copy this on the terminal:
python -m streamlit run app.py
